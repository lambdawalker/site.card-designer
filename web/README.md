# Card Designer frontend

From this directory: `npm ci`, then `npm --prefix ../packages/drawing-tools ci`, `npm run dev -- --host 127.0.0.1`, or `npm run build`. The production output in `dist/` contains Studio and the credential-free `/renderer.html` automation page. Proxy `/api/` to the Go backend in development.

Guests may edit built-in layouts and download sample PNGs. Sign in with Cognito to save private bundles, clone built-ins and manage read-only tokens. Access tokens live only in memory; refreshing requires signing in again. The OAuth state/PKCE transaction alone is kept in session storage, expires after ten minutes and is consumed once. Unsaved edits are not persisted across sign-in navigation.

The portrait browser requests an immutable package listing, loads whole packages as needed and caches packages in memory and browser Cache Storage. Server package caching is independent. Search covers packages already loaded in this browser session (initial package loaded if none are present); clear search and scroll to browse additional packages. The selected portrait's immutable revision, package path and row locator are preserved in `sample_source`, so reopened designs can resolve the same portrait. Downloaded images are embedded data URLs. Imported background rasters are embedded in the bundle and limited to 512 KB.

Template rendering uses Nunjucks in a fresh worker with a three second deadline, 500 KB source limit and 12 MB context limit. The worker receives design source, placeholder/data context and no credentials. Template fetch/XHR/WebSocket/importScripts are disabled. Deployment should additionally serve `template-worker-*.js` with `Content-Security-Policy: default-src 'none'; script-src 'self' 'unsafe-eval'; connect-src 'none'` (Nunjucks compiles expressions with Function). Preview iframes have an empty sandbox and their own restrictive CSP. Template editor accepts the Jinja-compatible expressions used in the catalog; arbitrary Python methods are unavailable. JavaScript generators encode synthetic QR, Code128 and PDF417 rather than personal fields.

`npm test` runs renderer, OAuth state, source formatting, download and sizing tests. `npm run test:browser` against a running dev/preview server checks all sixteen catalog variants, PNG signatures, the guest shell and sample download. Set `CARD_SERVER` and `CARD_CHROMIUM` to select the server/browser. Drawing package tests are separate (`npm --prefix ../packages/drawing-tools test`).
